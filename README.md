# Hotel Management System

## Technologies Used
- PHP
- MySQL
- HTML/CSS
- JavaScript

## Features
- Room booking
- Booking confirmation
- Booking cancellation
- Admin panel
- Database integration

## How to Run
1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Import `sourcecodester_hoteldb.sql` into phpMyAdmin.
4. Start Apache and MySQL.
5. Open:

http://localhost/hotel-management-system/Hotel/
